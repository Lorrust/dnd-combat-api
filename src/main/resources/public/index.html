D&D Combat API

Overview

D&D Combat API is a RESTful service to simulate battles between user-defined characters and monsters from the Dungeons & Dragons universe. It provides endpoints to fetch monster details, battle monsters, and inspect characters.

Endpoints

  • POST /api/battle/{monster} – Simulates a battle between your character and a monster.
  • GET /api/monsters/names/{page} – Get a list of monster names (1–65).
  • GET /api/monsters/{name} – Get details of a specific monster.
  • POST /api/characters/check – Validate your character.
  • GET /api/characters/example – Get a template example character.

Example

{
  "name": "Kaya",
  "strength": 10,
  "dexterity": 7,
  "hitPoints": 11,
  "armorClass": 12
}

Note: This project uses data from Open5e API for learning purposes.
