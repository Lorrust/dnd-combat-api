D&D Combat API

Overview

D&D Combat API is a RESTful service that allows you to simulate battles between custom characters and monsters from the Dungeons & Dragons universe. It provides endpoints for fetching monster details, running battles, and checking characters.

Features

  • Fetch a list of monster names with pagination.
  • Retrieve detailed monster stats by name.
  • Simulate combat between a user-defined character and a monster.
  • Validate a user-defined character.
  • Get a sample character for reference.

Endpoints

  • GET /monsters/names/{page} – Returns a paginated list of monster names (1–65).
  • GET /monsters/{monsterName} – Retrieves detailed stats for a specific monster.
  • POST /battle/{monsterName} – Simulates a battle between your character and a monster.
  • POST /character/check – Validates the details of a submitted character.
  • GET /character/example – Returns an example character template.

Note: This project uses data from the Open5e API for educational and non-commercial purposes.
