D&D Combat API

Overview

D&D Combat API is a RESTful web service that allows users to simulate battles between characters and monsters from the Dungeons & Dragons universe. It provides endpoints for fetching monster details, conducting battles, and retrieving a list of available monsters.

Features

  • Fetch a list of monster names.
  • Retrieve monster details by name.
  • Simulate combat between user-defined characters and monsters.
  • Check a user-defined character.
  • Get a template character to use as request body.

Endpoints

  • GET /monsters/{page} – Fetches a page of monster names (1–65).
  • GET /monsters/{name} – Retrieves details of a specific monster.
  • POST /battle/{monster} – Simulates a battle against a monster.
  • POST /check – Validate the details of your character.
  • GET /example – Provides an example character.

Note: This project uses data from the Open5e API for educational and non-commercial purposes.
